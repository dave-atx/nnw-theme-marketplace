# Repository instructions

Use `uv` for every Python command and keep the project on Python 3.14.

After every change to a Python file, run these commands before doing other
validation:

```sh
uv run ruff check --fix .
uv run ruff format .
uv run ruff check .
uv run ruff format --check .
```

Then run the focused tests affected by the change. Before finishing a Python or
catalog change, run the full unit suite and warning-strict Hugo build:

```sh
uv run python -m unittest discover -s tests -v
hugo --minify --panicOnWarning
```

`data/themes.json` is generated by `uv run build-catalog` and is kept in Git so
offline Hugo and pull-request builds work. `catalog/collections.json` is human
maintained policy. Never commit `.cache/download-history.json`; CI persists it
through GitHub Actions cache.

The production site is hosted under a GitHub Pages project path. Generate
internal links with Hugo `relURL` or `absURL`, never a root-relative `/path`.

Treat all GitHub and theme-package fields as untrusted. Do not weaken archive
size, traversal, symlink, required-file, or plist validation without tests and
an explicit reason. The install handoff must select from the generated catalog;
never redirect to an arbitrary query-string URL.

Use the installed `playwright-cli` for browser validation. Check installed
browsers with `playwright-cli install-browser --list`; do not invoke Playwright
through `npx`.
