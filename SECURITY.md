# Security policy

Theme listings link to community-controlled code and downloads. Inclusion is
not a security review or endorsement.

Report vulnerabilities in the marketplace generator, validation, install
handoff, or deployment privately through GitHub's **Report a vulnerability**
feature on the repository Security page. Please include reproduction steps,
affected URLs or files, and the impact. Do not include secrets or exploit
details in a public issue.

Vulnerabilities in NetNewsWire itself should be reported to the NetNewsWire
project. Problems confined to a listed theme should be reported to that
theme's repository owner.
